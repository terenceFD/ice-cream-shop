Fonts used by this website
==========================

Both typefaces are served locally from this folder as WOFF2 files.

1. Fredoka (fredoka-latin.woff2)
   - Designer: Graphi (released via Google Fonts)
   - Licence: SIL Open Font License 1.1 (OFL-1.1)
   - Source: https://fonts.google.com/specimen/Fredoka

2. DM Sans (dm-sans-latin.woff2, and any additional weight files in this folder)
   - Designer: Colophon Foundry (released via Google Fonts)
   - Licence: SIL Open Font License 1.1 (OFL-1.1)
   - Source: https://fonts.google.com/specimen/DM+Sans

The SIL Open Font License permits use, redistribution and embedding in any

font. The full licence text is available at:
